# Local LLM Lab — Hermes project context

Read `PROJECT.md` first, then `STATE.md`. Use `ENVIRONMENT.md` for observed machine/runtime facts and the other documents for experiment design and evidence.

This project is empirical: preserve exact model builds, configs, commands, measurements, and negative results. Do not start local inference, download large models, install software, change system configuration, or run an expensive experiment without explicit approval. Keep only one local model resident on the Mac.

`PROJECT.md` is the canonical scope and principles document; `STATE.md` is the short handoff for the next chat.

## Publishing results to GitHub

This repo is public (github.com/MichaelLeib/local-llm-lab). Publishing happens
**only on the user's explicit command** — never automatically. When the user
asks to publish: run `./publish.sh "<commit message>"` and nothing else. The
script scrubs personal data (usernames in paths, Tailnet IPs) mechanically,
verifies zero residue, forces the noreply commit identity, and pushes.
Rules: read `PUBLISHING.md`. Allowed: general system info. Never commit:
`backups/`, `worktrees/`, weights, vendored `source/`, real emails/tokens.
